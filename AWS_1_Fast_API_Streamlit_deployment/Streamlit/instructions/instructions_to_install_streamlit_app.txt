Step 1 Selectively clone  the repository
git clone --depth 1 --filter=blob:none --sparse \
  https://github.com/adebam/Rock_Classification.git

cd Rock_Classification

git sparse-checkout set AWS_Deployment/Streamlit

Step 2 Create an environment for the app
mamba create -n rock-streamlit python=3.12 pip -y

Step 3Activate the environment
conda activate rock-streamlit

Step 4 Enter the Streamlit folder and install dependencies
cd AWS_Deployment/Streamlit
python -m pip install -r requirements.txt

Step 5
Ensure AWS access is configured

##############################################
After installation of environment and want to launch the app. if u are on ec2 machine
1. Activate your environment
conda activate rock-streamlit
go to the location of the fast api
cd ~/Rock_Classification/AWS_Deployment/Streamlit

2. Start FastAPI
pkill -f "uvicorn fast_api_app:app"--- use this to kill any older fast api process
confirm the port is free 
ss -ltnp | grep 8000

nohup python -m uvicorn fast_api_app:app \
    --host 127.0.0.1 \
    --port 8000 \
    > fastapi.log 2>&1 &



3. Start Streamlit
confirm the port is free 
ss -ltnp | grep 8501

you might have to kill any previous streamlit
(("python",pid=3413,fd=6)) kill 3413 this command will kill 3413


nohup python -m streamlit run streamlit_app.py \
    --server.address=0.0.0.0 \
    --server.port=8501 \
    > streamlit.log 2>&1 &


#
# the public address is http://3.217.190.12:8501
#


Step 6
python -m streamlit run streamlit_app.py
OR
run this so that when you lose internet, your app doesn't die
nohup python -m uvicorn fast_api_app:app --host 127.0.0.1 --port 8000 > fastapi.log 2>&1 &
kill it by 
pkill -f "streamlit run streamlit_app.py"

Step 7
Locally, open http://localhost:8501.

OR
on ec2 use
nohup python -m uvicorn fast_api_app:app \
  --host 127.0.0.1 --port 8000 \
  > fastapi.log 2>&1 &

nohup python -m streamlit run streamlit_app.py \
  --server.address=127.0.0.1 --server.port=8501 \
  > streamlit.log 2>&1 &

For direct access, EC2 networking must allow inbound TCP port 8501 from your IP. Open http://YOUR_EC2_PUBLIC_IP:8501 in your browser.
